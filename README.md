# NRI Mitra – Website

Live Demo: **https://i-tmitra.vercel.app/index.html**

A clean, responsive, and informative website for **NRI Mitra**, designed to support NRIs by offering trusted assistance for families, elderly care, errands, and property-related services in India.

---

## 🚀 Project Overview

**NRI Mitra** provides essential ground-support services for NRIs living abroad.  
The website presents the service details, trust factors, coverage areas, and a contact form for easy inquiry.

### Key services include:
- Elderly care & in-home support  
- Daily errands & housekeeping assistance  
- Mobility support (lifts, transfers, activities)  
- Transportation to hospitals or appointments  
- Tenant & property management services  

---

## 🎯 Key Features

- Fully responsive design using **Bootstrap (no custom JavaScript used)**  
- Clear sections: About, Why Us, Services, Cities, Contact  
- Clean layout suitable for business & informational use  
- Contact form for user inquiries  
- Professional, mobile-friendly structure  

---

## 🛠️ Technologies Used

- **HTML5**  
- **CSS3**  
- **Bootstrap Framework** (for layout, responsiveness & components)  
- **No direct JavaScript** (Bootstrap features only)  
- Deployed via **Vercel**
